# Sample Constraint Generation Package

This directory represents the exact file structure generated by:

```bash
vendor/bin/agent-learning constraint-export \
  --root infra/doc/agent-learning \
  --proposal proposal.2026-06-13.001 \
  --output constraint-generation/proposal.2026-06-13.001
```

## Package Manifest

- `specification.json`: Machine-readable contract defining rule identity, engine, target path, boundaries, and validation commands.
- `source-findings.json`: Validated source findings that motivated this constraint.
- `source-proposals.json`: The approved human proposal record.
- `examples.json`: Few-shot training material containing source code of reference rules from the repository.
- `validation-plan.json`: Validation commands and required fixture files.
- `generation-prompt.md`: The instruction prompt provided to the L1 coding agent, explicitly instructing it to inspect `examples.json`.
